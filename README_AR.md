## التشغيل على Windows

استخدمي Python 3.13 أو 3.12. فكّي الضغط أولًا، ثم افتحي المجلد وشغّلي `RUN_WINDOWS.bat`؛ ينشئ بيئة محلية ويثبت المتطلبات ويفتح التطبيق. أول تشغيل يحتاج اتصالًا بالإنترنت لتثبيت المكتبات.

أو من Terminal داخل المجلد:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m streamlit run app.py
```

على macOS / Linux: شغّلي `bash run.sh`. لإيقاف التطبيق اضغطي Ctrl+C في Terminal.

- Overview: مؤشرات رئيسية، معاملات شهرية، نشاط المنتجات، أعلى العملاء، العملاء غير النشطين، وبطاقات Explore customers مع بحث وتقسيم صفحات.
- Customer detail: اختيار العميل، قائمة منتجات ببحث وسكرول، تمييز المنتج المختار، قفل بجانب المنتج غير المرتبط، أسهم تنقل، تفاصيل المنتج، خط زمني قابل للتمرير، مساهمة المنتجات، ومعاملات ونشاط العميل.
- رابط All products يفتح صفحة جدول كامل للمنتجات مع البحث وفتح المنتج والرجوع للرحلة. كل التسميات تستخدم Products.
- فلاتر العميل والمنتجات والفترة وإعادة التعيين. نقطة البداية كل العملاء وكل المنتجات وآخر 12 شهرًا.
- مساعد بيانات أسفل اليسار يجيب بحسابات فعلية من نطاق الفلاتر دون مفتاح API.
- لتبديل المصدر، استبدلي data/customer_journey.xlsx بملف بنفس التنسيق.

## البيانات

`data/customer_journey.xlsx` بيانات **تجريبية مصطنعة** وليست بيانات عملاء حقيقية. الفترة الافتراضية Oct 2025 – Sep 2026: 75 عميلًا، 546,530 معاملة، و7 عملاء غير نشطين. عميل Saudi National Bank لديه 390,000 معاملة و19 منتجًا مرتبطًا من 20. الأسماء Product 06–20 أماكن مؤقتة للاستبدال.

عدد المنتجات يأتي من البيانات؛ لذلك يظهر 20 في هذا الملف بدل نسخ رقم 5 غير المتوافق مع قائمة المنتجات في بعض شاشات التصميم. يمكن زيادة المنتجات دون تعديل الواجهة.

الأوراق الأربع المطلوبة (أسماء الأعمدة حرفية):

| الورقة | الأعمدة |
|---|---|
| Customers | customer_id, name, sector, created_at |
| Products | product_id, name, description, mdm_ready |
| Relationships | customer_id, product_id, first_use |
| Transactions | customer_id, product_id, month, transactions, last_transaction |

- IDs نصية وفريدة في بيانات العملاء والمنتجات.
- Relationships صف واحد لكل عميل ومنتج. المنتج المقفل يعني عدم وجود ارتباط، وليس صفر معاملات مفترضًا.
- Transactions صف واحد لكل عميل ومنتج وشهر؛ month أول يوم في الشهر وlast_transaction تاريخ في الشهر نفسه؛ transactions عدد صحيح غير سالب.
- التواريخ بصيغة YYYY-MM-DD. mdm_ready قيمة true/false. ورقة Metadata توثيقية اختيارية.
- عمر العلاقة من أول استخدام مسجل إلى نهاية الفترة المختارة؛ عدم النشاط بعد أربعة أشهر تقويمية دون معاملة. نسبة النمو تتطلب اكتمال الفترة السابقة المقارنة.
- نسب المعاملات والمجاميع تتغير مع الفلاتر. تاريخ أول استخدام معلومات عمرية؛ لا يعني اعتماد المنتج على المنتج السابق.
- استبدلي الملف بنفس الاسم قبل التشغيل أو ارفعيه من الإعدادات؛ الرفع خاص بالجلسة ولا يكتب فوق الملف الأصلي. يجب أن تبقى أسماء الأعمدة والأوراق مطابقة.

## المساعد

المساعد المحلي يدعم الإجماليات، أعلى العملاء، أعمار العلاقات، النمو، نسب المساهمة، أشهر الذروة، والمنتجات غير المرتبطة. أمثلة: `Total transactions`، `Top customers`، `Which products are not linked?`.

اختياريًا يمكن ضبط OPENAI_API_KEY وOPENAI_MODEL في بيئة الخادم ثم تفعيل Use optional AI wording. عند تفعيله تُرسل فقط صيغة السؤال والإجابة المحسوبة إلى OpenAI لإعادة الصياغة. لا يتضمن المشروع أي مفاتيح، والخيار مغلق افتراضيًا.

## تعديل التصميم والكود

- `frontend/styles.css`: الألوان، المسافات، المحاذاة، ونقاط استجابة الشاشة.
- `frontend/workspace.js`: الواجهات والفلاتر والرسوم والتفاعل.
- `app.py`: تشغيل Streamlit ورفع البيانات وربط المساعد.
- `data_model.py`: تحقق Excel وحسابات المساعد؛ `assistant.py`: إجابات المساعد.
- `assets/`: صور وأيقونات التصميم محليًا، دون اعتماد على روابط Figma المؤقتة.

تستخدم الواجهة Streamlit Custom Components v2 للمحافظة على ترتيب التصميم؛ لا تحتاج Node.js أو npm. المشروع يعمل محليًا، ولا يتضمن نشرًا أو اتصال قاعدة بيانات جاهزًا. يمكن استبدال طبقة تحميل البيانات لاحقًا بموصل قاعدة بيانات.

## إضافات هذا الإصدار

- `sql_lab.py`: تنفيذ الاستعلامات ضمن نطاق الفلاتر مع Authorizer وحدود الوقت والصفوف.
- `frontend/locales.json`: نصوص الواجهة العربية؛ أضيفي هنا أي تسميات جديدة.
- `data/demo_locations.json`: مواقع تجريبية؛ ليست جزءًا من ملف العملاء الحقيقي.
- `data/saudi_outline.json`: حدود جغرافية مبسطة، مصدرها johan/world.geo.json، محفوظة محليًا. لا تُرسل إحداثيات العملاء إلى خدمة خرائط خارجية.
- `SHOWCASE_GUIDE_AR.md`: مسار العرض وتغطية العناصر والمزايا وحدود الديمو.
- `test_sql_lab.py`: اختبارات تنفيذ SQL وسياقه وضوابطه.

الاستعلامات تستخدم SQLite وليس T-SQL؛ لا تتصلي بقاعدة الإنتاج عبر هذا المختبر. نطاق `transactions` هو العميل/المنتج/المدينة/الفترة المختارة، و`relationships` حتى نهاية الفترة، و`customers` ضمن نطاق العملاء المؤهلين.

المخطط الجغرافي في أي Excel بديل اختياري: أضيفي city وlatitude وlongitude إلى Customers. لن يستخدم التطبيق المواقع التجريبية للملفات البديلة. التفضيلات محفوظة في متصفح المستخدم؛ الاستعلامات والإجابات والأحداث مؤقتة في الجلسة، والأحداث لا تُضاف إلى Excel.

الخيار System يتبع النظام. Reduce motion يحترم إعداد النظام، ويوقف الحركة الإضافية. فتح ملف تقرير HTML ثم أمر Print يتيح Save as PDF؛ لا يوجد زر يولّد PDF على الخادم في هذا الإصدار.

جميع الاختبارات:

```bash
python -m unittest test_project test_sql_lab -v
```
